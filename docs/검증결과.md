원격 GitHub 저장소 업로드·Actions 실행·배포는 수행하지 않았습니다. 매월 1일 한국시간 04:00 목표의 확장 수집 workflow를 포함했습니다. 기존 저장소에 index.html뿐 아니라 data 및 전체 프로젝트와 .github/workflows/update-data.yml을 함께 반영해야 합니다. 로컬 ZIP을 여는 것만으로 자동 갱신이 시작되지는 않습니다.
