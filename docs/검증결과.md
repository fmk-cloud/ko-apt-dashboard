# k.apt_v24 검증 결과 — 2026-10-06

이번 버전은 영등포구 v23의 원천 자료와 매월 자동 갱신 코드를 유지하고 UI·전세 기준가 계산만 변경했습니다. 외부 배포와 GitHub Actions 실행은 수행하지 않았습니다.

## 새 동작 검증

Chromium 실제 브라우저에서 다음을 확인했습니다.

- 복구 버튼 오른쪽에 창 배치. 1600×1050 화면에서 왼쪽 106px, 위 127.8px, 너비 669.6px. v23의 540px에서 약 24% 확대.
- 저장본 1개에서 4개로 증가 시 위 좌표는 동일하고, 창 높이만 161.9px에서 354.2px로 증가. 고정·선택 복구·삭제 정상 작동.
- 복구창, ! 참고표, 지도 확대창 외부 여백 클릭으로 닫기. 지도 창을 닫아도 아래 참고표는 유지.
- 즐겨찾기 도구가 탭 오른쪽의 16px 간격에 왼쪽 정렬.
- 전체 화면 높이와 브라우저 높이 일치. 아파트 표 스크롤 끝에서 휠을 계속 내려도 전체 화면 scrollY=0. 모바일에서 표 높이 120px 이상과 복구창 화면 내 배치 확인. 상단 필터·즐겨찾기는 좁은 화면에서 내부 스크롤로 접근.
- 지하철 순위 총 50행, 왼쪽 1~25와 오른쪽 26~50. 마지막 건대입구역 50위, 길음역 순위 제거.

## 전세 계산 검증

시작월 2025.09 기준 2025.04~09 포함, 2025.03 이전과 2025.10 이후 제외. 4층 이상·최고층 제외·같은 실제 면적 ±0.1㎡·기본 신규 계약 조건을 확인했습니다. 층수 미상과 저층, 최고층, 다른 면적, 갱신(신규 모드)은 제외합니다. 갱신 포함 모드도 확인했습니다.

가상 검증: 6월 6.5억 1건, 5월 7억 1건, 4월 6억·6.2억 2건 → 총 4건 중 7억 최고가, 선정월 2025.05. 시작 매매 13.7억 − 전세 7억 = 갭 6.7억. 종료월만 바꿔도 갭 동일. 최고가 동률은 최근 거래월 우선. 비교 기간 첫 달(4월 1일) 포함 확인. 매매 선정이 시작월 이후 3개월을 초과하면 기존 규칙에 따라 갭 미산정.

실제 표시되는 모든 행의 전세가가 유효 자료 최고가와 일치하고, 갭은 시작 매매가에서 해당 전세를 뺀 값인지 확인했습니다. 상세 근거 표에서 선정 최고가 거래가 표시됩니다.

**당산푸르지오 59.7㎡:** 현재 포함 자료에는 2025.04~09 전세 거래가 없어 ‘시작월 포함 6개월 전세 없음’으로 표시됩니다. 사용자 진술의 전세 7억을 원천 거래로 추가하지 않았습니다.
