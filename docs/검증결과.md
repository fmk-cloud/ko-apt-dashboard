# v21 기능 검증 결과

이번 변경은 용적률·전세 연결 버전 v20의 영등포구 데이터를 그대로 사용했습니다. 원천 재수집 없이 UI·필터 계산·브라우저 저장을 수정했습니다.

- 대상 82개 단지, 매매 6,534건, 용적률 검증 41개, 전세 연결 79개 단지·11,099개 자료 행. 기존 데이터와 동일.
- 시작월 갭 검증: 시작 매매 13.7억 − 신규 전세 7억·8억 중앙값 7.5억 = 6.2억. 종료월만 바꿔도 갭 동일.
- 갱신 포함 선택 시 같은 예제 전세 중앙값 8억. 미래 전세·3개월 창 밖 전세·면적 불일치·저층·층수 미상 제외.
- 매매 선정이 시작월보다 4개월 이상 늦으면 갭 미산정. 기존 매매 계산 자체는 그대로 유지.
- 11회 연속 저장 후 10개 유지, 가장 오래된 미고정 항목 삭제 확인.
- 고정한 항목은 11번째 저장에서 유지, 미고정 항목 중 가장 오래된 항목 삭제. 10개 모두 고정 시 새 저장 차단.
- 저장 목록 새로고침 후 유지, 이전 단일 저장본 이관, 삭제한 단일 저장본이 다시 나타나지 않음 확인.
- 복구 목록 선택으로 모든 필터·전세 계약 조건·면적·선택 지역/역/APT 복원. 삭제는 현재 적용 필터를 변경하지 않음.
- 면적·범위 변경과 저장본 복구 후 되돌리기로 직전 세팅 복원. 저장 목록과 독립.
- 고정 아이콘 불투명도 100%, 미고정 20%, 고정 행 노란 배경 확인. 플랫폼에 관계없이 동일한 압정 그림을 사용.
- 숫자 스타일 검증: 전세·갭 RGB(36,101,178), 상승액과 시작 기준가 모두 16px·굵기 950, 상승률 기존 12.5px·굵기 950 유지.
- Chromium 실제 브라우저에서 오류 0건. 데스크톱과 모바일 복구창 확인.
- 기존 매매가격 계산 984가지 비교 일치. Python 수집 안전성 테스트 23개 통과. HTML 내장 데이터와 JSON 일치.

화면 캡처: dashboard.png, detail.png, restore.png, restore-mobile.png. 캡처는 테스트 중 선택한 설정입니다.
