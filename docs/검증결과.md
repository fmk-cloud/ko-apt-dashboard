### 범위와 한계

도보는 단지 지도 좌표와 OSM 출입구/역 좌표를 연결한 **보행망 추정**입니다. 실제 단지 출입문을 일일이 확인한 네이버 지도 길찾기 값이 아닙니다. 이 기준에서 연결이 확인되지 않은 단지는 빈칸을 유지합니다. 출입문 선택, 공사, 지도 누락, 통행 제한은 현장에서 다를 수 있습니다. 계산 시 유효하지 않은 도로·건설 중 길·보행금지·사유지 통행금지 등은 제외했지만 원천 표기의 정확도를 보장하는 것은 아닙니다. 메모는 현재 브라우저에 저장하며 다른 기기에 동기화되지 않습니다. 원격 GitHub 업로드·Actions 실행·배포는 이번 작업에서도 수행하지 않았습니다.
