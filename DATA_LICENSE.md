The walking-network-derived station links in data/transport-links.json and the corresponding station_walks fields use OpenStreetMap data, © OpenStreetMap contributors, available under the Open Database License (ODbL) 1.0.

- Source extract: https://download.geofabrik.de/asia/south-korea.html
- Initial source timestamp: 2026-10-06T20:21:06Z

The distributed station-link database is provided under ODbL 1.0. The original source extract can be obtained from Geofabrik. Reproduction is implemented in scripts/extract_walk_network.py and scripts/build_transport_links.py. Source hash, route node IDs, endpoint IDs and assumptions are recorded with the data.

Apartment coordinates originate from the public K-apt map; the source identifier is recorded per apartment. Sale, lease and other official apartment data retain the source information in the existing records. This licence note applies to the OSM-derived transport data, not to unrelated price data or the supplied memo artwork.
