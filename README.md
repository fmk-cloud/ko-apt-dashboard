# k APT Dashboard v12

## 포함 범위
- 서울 25개구
- 경기 주요지역: 과천, 성남(분당/수정/중원), 광명, 하남, 평촌(안양 동안구),
  수지, 광교(수원 영통/수지 상현), 동탄, 삼송/지축, 일산, 의왕, 구리
- 국토교통부 아파트 매매 실거래
- 국토교통부 아파트 전월세 실거래 중 월세 0원인 순수 전세
- K-apt 세대수/사용승인일/인근 지하철역/도보시간
- 건축HUB 용적률

## 가격 규칙
- 저층 1~9층 제외
- 최상층 제외
- 시작 기준월 거래가 있으면 그 달 최고가
- 시작 기준월 거래가 없으면 이후 첫 거래월 최고가
- 최근 기준월 거래가 없으면 이전 가장 최근 거래월 최고가
- 59㎡가 없으면 전용 49~74.99㎡ 중 59㎡에 가장 가까운 타입으로 대체
- 84㎡는 82~86.5㎡

## 지하철 필터
K-apt의 인근 지하철역/도보시간을 사용합니다. 20분 이내인 경우에만 해당 역 필터에 포함합니다.
기존 데이터에 실제 거리(km)가 있으면 1.35km 이내를 보조 기준으로 사용합니다.

주의: K-apt의 '인근역'은 단지에 등록된 대표 인근역 정보라서,
모든 출입구 기준 실제 보행경로를 완전히 계산하는 길찾기 API와는 차이가 있을 수 있습니다.

## GitHub Secrets
기존 `PUBLIC_DATA_API_KEY`를 사용합니다.

추가 서비스의 권한이 같은 키에 연결되어 있지 않다면 공공데이터포털에서 아래 서비스를 활용신청하세요.
1. 국토교통부_아파트 매매 실거래가 상세 자료
2. 국토교통부_아파트 전월세 실거래가 자료
3. 국토교통부_공동주택 단지 목록/기본 정보제공 서비스
4. 국토교통부_건축HUB 건축물대장정보 서비스

모두 같은 공공데이터포털 서비스키를 쓸 수 있으면 `PUBLIC_DATA_API_KEY` 하나로 충분합니다.
별도 키를 쓰는 경우 선택적으로 `KAPT_API_KEY`, `BUILDING_HUB_API_KEY` Secret을 추가할 수 있습니다.

## 처음 적용
1. 이 ZIP의 파일을 GitHub 저장소 루트에 덮어쓰기
2. `.github/workflows/update-data.yml`까지 포함해 Commit
3. GitHub → Actions → `Update apartment dashboard data`
4. `Run workflow` → `full`, `enrich_far=true`
5. 완료 후 봇이 `index.html`과 `data/site-data.json`을 자동 Commit
6. Vercel은 GitHub Commit을 감지해 자동 재배포
