# k APT Dashboard v16 — 영등포구 수정판

이번 버전은 외부 API를 호출하지 않습니다.

## v15에서 확인된 실제 오류
1. 시작 기준가/신뢰도 팝업의 `적용` 버튼이 새 필터 함수가 아니라 예전 함수를 계속 가리키고 있었습니다.
   그래서 화면에서 값을 골라도 실제 필터 상태가 바뀌지 않았습니다.
2. 신뢰도 기본값이 `중○~상●`라서 당산현대5차처럼 최근 59㎡ 거래가 오래된 단지가 기본 화면에서 숨겨졌습니다.
3. 정적 데이터에서 당산강변래미안3차의 거래가 0건이었습니다.
4. 용적률 데이터가 전부 비어 있었습니다.

## v16 수정
- 시작 기준가/신뢰도 적용 버튼 이벤트 재연결
- 신뢰도 기본값 `전체`
- 당산현대5차 다시 표시 가능
- 당산강변래미안3차 55.91㎡ 거래 보강
- 주요 당산 단지 용적률 보강
  - 당산푸르지오 355%
  - 당산현대5차 373%
  - 당산강변래미안3차 336.57%
  - 영등포삼환 369%
  - 당산동1차효성아파트 280%
  - 당산2차효성타운 269%
