# k APT Dashboard v15 — 영등포구 안정화판

이번 버전은 데이터 재수집을 하지 않습니다.

목적은 한 가지입니다.
**이미 확보된 영등포구 데이터를 이용해 사이트/UI/필터/Vercel 배포가 정상인지 먼저 확인합니다.**

## 데이터
- 영등포구 160개 단지 내장
- 기존 확보 매매 실거래 및 단지 메타데이터 사용
- 기준 기간: 2025.09 ~ 2026.09
- 외부 API 호출 없음

## 수정한 핵심 오류
기존 코드에서 `Number(null)`이 `0`이 되어,
용적률이 비어 있는 단지가 기본 `100% ~ 이상` 필터에서 전부 탈락하는 문제가 있었습니다.
v15에서는 `null/빈값`을 숫자로 취급하지 않도록 수정했습니다.

세대수 미확인값도 같은 방식으로 방어했습니다.

## GitHub/Vercel
ZIP을 기존 저장소에 덮어쓰고 Commit만 하면 됩니다.
**Actions에서 데이터 업데이트를 실행할 필요가 없습니다.**
Vercel은 index.html 변경 Commit을 보고 자동 배포합니다.

Actions의 `Validate static Yeongdeungpo dashboard v15`는
데이터를 수집하지 않고 파일이 정상인지 검사만 합니다.
