# k APT Dashboard v17 — 영등포구

## v17 변경
- 시작 기준월 거래 없으면 이후 첫 거래월을 계속 탐색
- 최근 기준월 거래 없으면 이전 최근 거래월을 계속 탐색
- 같은 거래월 1건만 사용할 수 있어도 시작/최근에 동일하게 사용 → 상승폭 0
- 저층 제외 기준: 1~3층
- 최고층 제외 유지
- 신뢰도:
  - 시작/최근 각각 기준월과 5개월 이내면 거래시점 감점 없음
  - 6~8개월 이탈: 중
  - 9~11개월 이탈: 하
  - 12개월 이상: 최하
  - 시작/최근 선정 거래의 층 차이가 10층 이상이면 최소 중
  - 시작가 직전 1~2개월에 더 높은 거래가 있으면 최소 중
- 각 필터 팝업: `전체 / 초기화 / 취소 / 적용`
- 상단: `전체 / 저장 / 불러오기`
  - 저장/불러오기는 브라우저 localStorage 사용
- 주요 당산 단지 용적률 보강
- 당산효성1차 59.85㎡ 거래 보강
