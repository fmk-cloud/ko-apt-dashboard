# k APT Dashboard v18 — 영등포구 검증판

## v17에서 화면 전체가 멈춘 원인
- `use strict` 상태에서 `filterComplex=function(...)`처럼 선언 없이 대입해 브라우저가 `ReferenceError`를 냈습니다.
- 그래서 초기화가 중단되어 지역칩, 순위표, 시작 기준가 팝업이 전부 작동하지 않았습니다.
- 또 HTML 안에 영등포구 160개 데이터와 예전 3개구 396개 데이터가 동시에 들어 있었습니다. v18은 데이터 원본을 `window.__EMBEDDED_DATA__` 하나로 통합했습니다.

## v18 UI
- 좌상단 `전체 / 저장 / 불러오기`는 세로 배치
- 상단 `전체`: 기간/세대수/시작 기준가/용적률/갭/준공/신뢰도를 제한 없는 범위로 열고 수록 지역 전체를 선택
- 필터 팝업: `전체 / 불러오기 / 취소 / 적용`
  - `불러오기`는 상단 `저장`으로 저장한 프리셋에서 해당 필터 값을 불러온 뒤 `적용`할 수 있음
- 외부 API 호출 없음. Commit만 하면 Vercel 자동 재배포

현재 v18. 다음 수정은 v19입니다.
