# k APT Dashboard v13 — 4개구 파일럿

이번 버전은 처음부터 서울·경기 전체를 수집하지 않습니다.

## 수집 지역
- 성동구
- 마포구
- 동작구
- 영등포구

## 수집 데이터
- 아파트 매매 실거래
- 아파트 순수 전세 실거래(월세 0원)
- K-apt 세대수 / 사용승인일 / 인근 지하철역 / 도보시간
- 건축HUB 용적률
- 59㎡ / 84㎡ 가격 비교
- 59㎡가 없는 단지는 같은 20평대(전용 49~74.99㎡)에서 59㎡에 가장 가까운 타입으로 대체

## 실행
GitHub → Actions → `Update 4-district apartment dashboard`
→ Run workflow
→ `enrich_far = true`

한 번만 누르면 매매/전세/K-apt/용적률 → 검증 → index.html 내장 → 자동 commit까지 이어집니다.
브라우저를 닫아도 GitHub 서버에서 계속 실행됩니다.

## 실패 방지
- 한 작업의 제한시간을 120분으로 설정
- API 단일 요청 timeout 20초, 최대 3회 재시도
- K-apt 목록도 서울만 조회
- 전체 서울·경기가 아니라 4개구만 수집

현재 v13. 이후 작은 수정이라도 v14, v15 ... 순서로 올립니다.
